# LinkedIn

Use LinkedIn for polished credibility, build stories, lessons, and opportunity-facing posts.

## Style

- Short paragraphs
- Strong verbs
- One main point
- No fake thought-leader cadence
- No hashtags by default
- Metrics need context

## Archetypes

- Build story: situation, mechanism, result, meaning.
- Tactical lesson: claim, why it matters, mechanism, proof, takeaway.
- Quick use-case: thing shipped, how it works, payoff.
- Point-of-view: observation, take, reasoning, implication.

## Gate

Before returning, check:

- Does the first line create tension without clickbait?
- Is there one main idea?
- Are claims grounded or clearly framed as opinion?
- Would a busy reader understand the point quickly?
