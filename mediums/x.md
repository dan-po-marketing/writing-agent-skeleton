# X / Twitter

Use X for builder notes, sharp observations, and lightweight public thinking.

## Style

- Open on the point
- Lower formality is allowed
- No hashtags by default
- No engagement bait
- Single post by default
- Thread only when the user explicitly asks

## Best Forms

- Build note: what was shipped, broken, or learned today.
- Sharp take: one observation with a clear edge.
- Result-first story: outcome first, then mechanism.
- Tactical note: useful detail, no long setup.

## Gate

Before returning, check:

- Does it sound human?
- Is there one idea?
- Is the first line the take or result?
- Would a builder find it specific rather than generic?
