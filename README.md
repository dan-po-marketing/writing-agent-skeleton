# Writing Agent Skeleton

Reusable prompt-and-process scaffold for a personal writing agent.

The repo gives an AI assistant a durable workflow for turning rough notes into platform-ready writing while preserving voice, honesty boundaries, and review gates.

## What is included

- `AGENTS.md`: operating instructions for the writing agent.
- `pipeline.md`: scope, frame, draft, critique, and score workflow.
- `mediums/`: medium-specific style and quality gates.
- `voice/voice-kernel.md`: replaceable voice rules.
- `content/README.md`: suggested post storage model.
- `feedback/learnings.md`: place to promote repeated edit feedback into durable rules.

## What is not included

- Private drafts
- Personal proof points
- Social account tokens
- Analytics exports
- Scheduling credentials

## Built with Codex

Codex was used to extract a public-safe skeleton from a private writing workflow without publishing private drafts, metrics, or personal positioning notes.
