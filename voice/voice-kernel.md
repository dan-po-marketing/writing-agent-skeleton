# Voice Kernel

Replace this file with the user's real voice rules in a private workspace.

## Default Voice Rules

- Prefer concrete mechanisms over abstract labels.
- Use short lines for the most important turns.
- Cut repeated explanations.
- Avoid overclaiming.
- Keep authority grounded in what the user can prove.
- Let the writing sound like a person, not a brand guide.

## Honesty Rules

- If evidence is missing, say so.
- If a claim is opinion, frame it as opinion.
- If a metric appears, include context.
- If a story involves another person or company, remove private details unless the user explicitly approves publication.
